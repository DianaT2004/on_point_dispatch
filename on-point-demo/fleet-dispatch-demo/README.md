# OnPoint - AI-Powered Logistics Platform

A modern, intelligent logistics management platform for truck drivers and fleet operators in Georgia.

## Features

- 🤖 **AI-Powered Load Matching** - Smart algorithms match drivers with optimal loads
- 🗺️ **Interactive Route Maps** - Real-time route visualization with Georgian cities
- 📱 **Mobile-First Design** - Fully responsive on all devices
- 🎯 **Emergency Services** - Quick access to fuel, mechanics, and towing
- 💬 **Integrated Chat** - Communicate with dispatchers and shippers
- 📄 **Document Management** - Store and manage BOL and shipping docs
- 🏆 **Celebration Animations** - Rewarding user experience

## Tech Stack

- **React 18** with TypeScript
- **Vite** for blazing-fast development
- **Tailwind CSS** for modern styling
- **Zustand** for state management
- **React Router** for navigation
- **Lucide React** for beautiful icons

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

```bash
npm run build
```
