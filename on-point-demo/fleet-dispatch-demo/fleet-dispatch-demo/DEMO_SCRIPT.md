## 💡 Pro Tips for Recording

### Before Recording:
- [ ] Clear browser cache
- [ ] Close unnecessary tabs
- [ ] Turn off notifications
- [ ] Set screen resolution to 1920x1080
- [ ] Open dev tools and set mobile viewport if showing mobile
- [ ] Have demo credentials ready

### During Recording:
- [ ] Move mouse smoothly, not quickly
- [ ] Let animations complete before next action
- [ ] Pause briefly on important information
- [ ] Keep cursor away from critical UI elements when speaking
- [ ] Use consistent timing between actions

### Animation Timing Reference:
- Login loading: 1.5 seconds
- AI Scan: 2 seconds (20 steps × 100ms)
- Auto-dispatch: 7.5 seconds (5 steps × 1.5s)
- Document generation: 1.8 seconds (15 steps × 120ms)
- Service request: 2 seconds (drafting + sending)

### Emphasis Points:
1. **AI Scoring** - "95% Excellent Match"
2. **One-Click Automation** - "30 minutes to 30 seconds"
3. **Visual Polish** - Smooth animations throughout
4. **Complete Workflow** - From finding loads to delivery

### Common Mistakes to Avoid:
- ❌ Don't click too fast - let animations show
- ❌ Don't skip the AI scan animation
- ❌ Don't rush through auto-dispatch steps
- ❌ Don't forget to highlight AI scores
- ❌ Don't overlook the mobile responsiveness
